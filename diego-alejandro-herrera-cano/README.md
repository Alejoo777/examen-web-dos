# Librería Archivo — Migración a React

Migración de la aplicación vanilla (`proyecto-js-vanilla`) a React + Vite con React Router DOM.

## Ejecutar

```bash
npm install
npm run dev
```

## Estructura

```text
src/
├── components/   # Layout, Navbar, Footer, HeroBanner, BookCard, StatCard, FiltrosCatalogo, ContactInfoItem, Icono
├── pages/        # Inicio, Catalogo, Contacto
├── routes/       # router.jsx (createBrowserRouter)
├── data/         # datos.js (mock de libros)
├── styles/       # styles.css
├── App.jsx       # RouterProvider
└── main.jsx      # Punto de entrada
```
